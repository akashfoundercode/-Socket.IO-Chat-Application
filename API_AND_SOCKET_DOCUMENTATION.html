1. Authentication & Profile REST APIs

Request Body

{ "phone": "9876543210", "countryCode": "+91" }

{ "success": true, "message": "OTP sent successfully", "otp": "123456" }

6. Socket.IO Real-time Events Specification

A. Client-to-Server Events (Frontend Emits)

Event Name Payload Description
join userId: string Registers user socket and joins personal room.
loadConversation otherUserId: string Loads 1-on-1 messages and activates chat focus.
mark_seen { otherUserId } Double Blue Tick trigger for 1-on-1 messages.
message { to, text, type, mediaUrl, replyToId } Sends 1-on-1 message (text, voice, photo, video, location).
message_reaction { messageId, emoji, to } Reacts to 1-on-1 message with emoji.
edit_message { messageId, text, to } Edits sent message.
delete_message { messageId, deleteFor: me|everyone, to } Deletes message.
typing { to, isTyping: boolean } Broadcasts live typing status.
loadGroup groupId: string Joins group room and loads details/messages.
group_message { groupId, text, type, mediaUrl } Sends message to all group members.
group_reaction { groupId, messageId, emoji } Reacts to group message with emoji.
group_call_user { groupId, callerName, callType, channelName } Starts Agora group voice/video call.
group_call_response { groupId, channelName, accepted, agoraUid } Accepts/declines group call.
group_call_media_status { groupId, isMuted, isVideoOff } Toggles mic/camera in group call.
call_user { to, callerName, callType, channelName } Starts 1-on-1 voice/video call.
answer_call { to, channelName } Accepts 1-on-1 call.
reject_call { to, channelName, reason } Declines 1-on-1 call.
end_call { to, channelName } Hangs up call and saves duration.

B. Server-to-Client Events (Frontend Listens)

Event Name Payload Description
online_users string[] Real-time array of all active online user IDs.
message_saved Message Delivery acknowledgment (Single Gray Tick ✓).
messages_delivered { to, recipientId } Recipient received message (Double Gray Tick ✓✓).
messages_seen { to, by } Recipient opened message (Double Blue Tick ✓✓).
message_received Message New inbound 1-on-1 message.
group_details Group Full group info with hierarchy sorted members.
group_message_received GroupMessage New inbound group message.
incoming_call { from, callerName, callType, channelName } Incoming 1-on-1 call with ringtone trigger.
call_ringing { channelName } Recipient device is ringing (dial tone trigger).
call_accepted { from, channelName } Call answered, connect to Agora channel.
call_ended { channelName, duration } Call terminated, close modal.
incoming_group_call { groupId, callerName, callType, channelName } Incoming group call banner & popup.
group_call_user_joined { agoraUid, userName } Participant joined Agora group call grid.
group_call_user_left { userId } Participant exited group call.
